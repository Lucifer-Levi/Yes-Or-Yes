# 💗 Love Proposal Website

A cute, romantic website designed to ask a special someone to make things official. 💍💕

### ✨ Features
- Pink, white, and purple love-themed design
- Romantic messages and emojis
- Interactive **Yes** and playful **No** buttons
- Floating hearts and celebration effects
- Personal kitten photo

### 🛠️ Built With
- HTML
- CSS
- JavaScript

### 🚀 How to Run
1. Download or clone this repository.
2. Keep `index.html` and `cl.jpg` in the same folder.
3. Open `index.html` in your browser.
